# Porteiro do Inferno

Porteiro do Inferno is a Minecraft Bedrock Edition mod that introduces a terrifying demonic entity to protect the gates of hell. The mod features a custom entity with unique visuals, animations, and sounds, along with an advanced AI system that interacts with players through synthesized voice. The entity reacts to player actions, controls access to a hellish dimension, and engages in dynamic dialogues.

## Install

1. Download the mod from the GitHub repository.
2. Place the mod file in the `behavior_packs` folder of your Minecraft Bedrock Edition world.
3. Launch Minecraft and load your world.

## Use

1. Spawn the `shadowbox:porteiro_inferno` entity near a hellish gate.
2. Interact with the entity to initiate dialogues and control access to the hellish dimension.
3. Observe the entity's reactions to your actions and items.
